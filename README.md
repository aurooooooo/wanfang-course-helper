# 万方课程助手

为万方培训站点提供一个可拖动的课程辅助面板：查看当前课件累计观看时长与任务进度，在设置中调整倍速、自动播放、下一节跳转和任务停滞刷新。

**当前版本：1.7.0** · **默认 1× 播放**

[安装脚本](https://raw.githubusercontent.com/aurooooooo/wanfang-course-helper/main/wanfang-background.user.js) · [查看源码](./wanfang-background.user.js) · [反馈问题](https://github.com/aurooooooo/wanfang-course-helper/issues)

## 能做什么

- **后台继续播放**：处理课程页面切到后台后的自动暂停检测。
- **暂停后自动播放**：初次进入课程、新视频加载或后续暂停时尝试恢复，可随时关闭；不会重新播放已结束的视频。
- **倍速选择**：默认 1×，可选 1、1.5、2、3、4、8×。
- **自定义下一节跳转**：自行决定是否跳转，以及播放到多少百分比后跳转，支持 1–100% 的整数。
- **章节计时接续**：修复切换下一节后学习计时器失效的问题；新视频实际播放后接续平台原有计时逻辑，自动和手动切换均适用。
- **任务时长进度**：按当前课件的累计观看时长 ÷ 课件总时长显示百分比和进度条，同时展示累计观看时间与总时长。
- **两分钟停滞刷新**：持续播放时，累计观看时长两分钟没有增长则自动刷新，保留当前章节与设置；可在设置中关闭。
- **简洁状态面板**：展示课程标题、播放状态、实际倍速和任务时长；播放、跳转和刷新选项收在“设置”中。
- **拖动与日志**：拖动标题栏调整位置，展开“日志”查看最近 60 条运行记录。

> 面板中的百分比来自平台页面的当前课件累计观看时长，不再使用视频播放位置。自动下一节仍按视频播放百分比触发。页面时长不代表已验证的服务器保存结果，课程完成状态以平台为准。

## 适用页面

面板在整个 [万方培训站点](https://cx.wanfangdata.com.cn/e-training)及其子路径显示，包括：

| 页面 | 行为 |
| --- | --- |
| 培训首页、课程列表 | 显示面板，等待进入视频课程 |
| 精品课程 `/e-training/quality/courselearn` | 检测当前播放器并执行设置 |
| 讲座课程 `/e-training/lecture/courselearn` | 检测当前播放器并执行设置 |

需要通过网站正常登录。无需填写课程 ID；从培训首页通过站内链接进入课程时，已有脚本会继续检测，页面重新渲染移除面板时也会尝试恢复。

当前适配范围是此站点的网页视频课程，其他培训系统和手机 App 未适配。

## 安装与更新

推荐使用 **Tampermonkey（油猴）**：

1. 从 [Tampermonkey 官网](https://www.tampermonkey.net/)安装对应浏览器的扩展。
2. 按扩展提示启用用户脚本执行权限，具体操作见 [官方权限说明](https://www.tampermonkey.net/faq.php?q=Q209)。
3. 点击 [安装脚本](https://raw.githubusercontent.com/aurooooooo/wanfang-course-helper/main/wanfang-background.user.js)，在扩展安装页确认安装。
4. 登录万方，打开培训页面并刷新一次，确认右下角出现“课程助手”。
5. 展开“设置”，选择需要的播放和跳转方式。若首次自动播放被浏览器阻止，请手动点击播放一次。

**已安装旧版**：更新或替换现有脚本，再刷新已经打开的培训页面一次。不要同时启用多个副本。

如果安装链接只显示源码：在 Tampermonkey 中“添加新脚本”，删除模板，粘贴 [脚本文件](./wanfang-background.user.js)的全部内容并保存，保留顶部 `==UserScript==` 元信息，然后刷新培训页面。参见 [官方安装说明](https://www.tampermonkey.net/faq.php?q=Q102)。

## 设置怎么用

点击面板中的 **“设置”**，所有播放选项都在这里：

| 设置项 | 默认值 | 使用方式 |
| --- | --- | --- |
| 播放倍速 | **1×** | 选择 1、1.5、2、3、4、8×，后续章节沿用；实际支持范围取决于浏览器与播放器 |
| 暂停时自动播放 | **开启** | 取消勾选后保留暂停状态，下一节也由自己手动播放 |
| 自动跳转下一节 | **开启** | 勾选开启、取消关闭，可以反复调整；关闭后仍可调速和自动播放 |
| 跳转进度 | **95%** | 输入 **1–100 的整数**；100% 表示播完后跳转 |
| 任务停滞时刷新 | **开启** | 持续播放且累计观看时长 **120 秒**未增长时刷新；取消勾选后只显示进度与日志 |

跳转进度按**视频播放位置**计算，与面板的任务时长百分比分开。输入后，移开焦点或按 Tab 生效。非法输入会提示并恢复原设置。关闭自动跳转时也能先调整进度，重新开启后按当前播放位置执行。

例如：

- **正常速度播完再进入下一节**：1×，开启自动跳转，进度设为 100%。
- **保留原来的跳转方式**：开启自动跳转，进度设为 95%。
- **自己决定何时进入下一节**：关闭自动跳转。
- **允许自己暂停视频**：关闭“暂停时自动播放”。

如果当前播放位置已经达到新设定的进度，下一次检查就可能跳转。视频在暂停且未结束时不会直接跳转；自动播放开启后可能先恢复播放，再按进度跳转。

后续章节沿用当前设置。**脚本触发的停滞自动刷新会保留当前章节、倍速、播放与跳转开关、跳转进度和刷新开关**；手动刷新或重新打开页面恢复默认值。面板位置和日志不会跨页面刷新保存。

## 看懂面板

- **● 运行中**：监控程序正在工作；视频是否播放，要看进度区域的“播放中 / 已暂停 / 已结束”。
- **● 跳转关闭**：只关闭了自动进入下一节，其他播放功能仍按设置工作。
- **等待课程播放器**：当前没有可识别的视频，进入视频课程后会继续检测。
- **任务进度 / 累计观看**：来自当前课件的平台累计观看时长与总时长，通常约每分钟更新；无法读取时显示“—”，不会用视频进度代替。
- **标题栏**：可用鼠标或触摸拖动；聚焦后用方向键每次移动 10 像素。
- **设置 / 日志**：默认折叠，点击展开。日志记录启动、调速、进度设置、跳转和异常提示。

遇到随堂测验、没有下一节按钮、下一节超过 20 秒仍未加载，或无法识别课程计时组件时，脚本会关闭自动跳转，并取消对应勾选。检查页面或手动完成测验，回到有效视频课程后，可在设置中重新开启。

## 下一节的学习计时修复

1.6.1 修复了已检查的站点前端中的一种计时故障：章节切换清除了计时器，但旧编号仍保留，导致后续播放回调无法重新启动学习计时。

脚本在章节切换后清理失效编号，等待新视频加载并实际播放，再通过网站原有的播放回调启动计时。关闭自动播放时，暂停的新视频不会由修复逻辑启动计时；加载等待期间也不会被补计为新章节的观看时长。已有正常计时器会保留，重复运行或清理脚本时会恢复原章节切换方法。

升级后请刷新已打开的课程页一次。日志会显示“已启用章节切换计时修复”；发生修复时显示“已清理章节切换后失效的学习计时器”和“当前章节的学习计时已启动”。网站通常约每分钟提交一次学习记录，下方时长不会逐秒更新。

修复依赖当前页面的 Vue 课程组件。未识别到组件时，脚本会关闭自动跳转并提示，避免继续切到无法接续计时的章节。它不自行调用学习记录接口，不补写此前丢失的时长，也不保证服务器接受或保存每次请求。

## 两分钟停滞自动刷新

检测使用平台累计观看的**原始秒数**，避免显示百分比四舍五入后造成误判。持续播放且视频已加载时，连续 120 秒没有增长便自动刷新；暂停、加载、拖动进度、章节切换、播放结束、任务时长已满、测验或无法读取任务时长时不触发。恢复播放或换章节后重新计时。浏览器后台节流或冻结可能推迟检测。

自动刷新按网站的章节参数定位当前课件，并用当前标签页的 `sessionStorage` 暂存恢复信息；新页面读取后删除，超过 10 分钟的记录失效。存储不可用或无法定位章节时会关闭自动刷新并提示手动处理。

如果同一章节在自动刷新后再次停滞两分钟，脚本会**关闭自动刷新并记录日志**，避免循环重载。查看网站时长和学习记录请求，解决异常后可在设置中重新开启。实际时长增长或进入新章节后会解除该章节的重复刷新限制。

自动刷新只重新加载页面，不提交或修改学习记录；视频播放位置由网站自己的恢复逻辑决定。

## 常见问题

| 问题 | 处理方式 |
| --- | --- |
| 没有面板，或站内跳转后需要刷新才出现 | 确认位于培训站点、脚本已启用且有执行权限；更新到当前版本后先刷新一次 |
| 视频不能自动播放 | 确认“暂停时自动播放”已开启；首次播放被浏览器阻止时先手动播放一次。失败后脚本每 5 秒重试，避免日志连续刷屏 |
| 视频暂停后又播放 | 这是默认自动播放行为；在设置中关闭“暂停时自动播放”即可 |
| 达到设定进度仍未跳转 | 检查跳转开关、进度设置、播放状态与网站下一节按钮；后台定时器被节流时，跳转可能延迟 |
| 自动跳转突然关闭 | 查看日志；测验、最后一节或下一节加载超时都会关闭跳转，可按页面情况重新开启 |
| 高倍速不生效 | 选择较低倍速并查看日志；下拉框中的选项不代表所有浏览器都支持 |
| 设置刷新后恢复了 | 手动刷新恢复默认设置；脚本触发的停滞自动刷新会恢复当前章节和设置 |
| 下一节正常播放，但下方时长不增加、学习记录请求停止 | 更新到 1.7.0 并刷新一次；脚本先接续原生计时，持续播放两分钟任务时长仍不增长时自动刷新。仍异常时查看日志和 `insertrecord` 请求 |
| 自动刷新停止了 | 同一章节刷新后仍停滞时会关闭刷新开关；存储不可用或无法定位章节也会关闭，日志中说明原因 |
| 任务进度显示“—” | 当前页面没有可读取的累计观看时长或总时长；不会据此判断停滞或刷新 |
| 提示未识别到课程计时组件 | 确认只启用一个脚本副本，刷新后再试；网站结构或脚本执行环境可能变化，当前版本会关闭自动跳转，可手动切换并反馈问题 |
| 播放位置已到末尾，但课程未完成 | 检查平台累计观看时长；视频位置不等于实际观看时长 |

后台播放不涵盖关闭标签页、电脑睡眠或浏览器冻结标签页。脚本不会自动答题、绕过课程访问权限或伪造学习记录，也不保证平台认定课程完成。

## 临时运行与停用

也可在已登录的课程页面，打开开发者工具的 Console，审阅并粘贴 [脚本源码](./wanfang-background.user.js)的全部内容执行。临时运行只对当前文档生效，自动或手动刷新后均需要重新运行；要在自动刷新后继续监控，请通过 Tampermonkey 安装。控制台不允许粘贴时，可改用 Tampermonkey。

彻底停用：Tampermonkey 方式先禁用脚本再刷新；Console 方式直接刷新。不要同时安装和临时执行不同版本。

## 反馈与许可

请在 [Issues](https://github.com/aurooooooo/wanfang-course-helper/issues)提供浏览器版本、脚本版本、复现步骤和相关日志，移除密码、验证码、Cookie、Token 及个人信息。

脚本不主动读取账号密码、Cookie 或 Token，不内置第三方统计或外部依赖；日志只保存在当前页面内存中，自动刷新恢复信息临时存于当前标签页的 `sessionStorage`。Tampermonkey 可按扩展的更新设置从本仓库检查和获取新版。
