# 万方课程助手

用于万方科研诚信培训系统的浏览器用户脚本。面板在整个 `/e-training` 站点显示，提供后台继续播放、倍速调节、可关闭的暂停后自动播放、可设置触发进度的自动下一节，以及可拖动的状态和日志面板。当前版本：**1.6.0**。

**[安装脚本](https://raw.githubusercontent.com/aurooooooo/wanfang-course-helper/main/wanfang-background.user.js)** · [查看源码](./wanfang-background.user.js) · [反馈问题](https://github.com/aurooooooo/wanfang-course-helper/issues)

> 倍速播放不会同步增加平台累计观看时长。2 倍速播放到视频的 95%，本次实际只经过原视频时长的约 47.5%；课程可能仍未达标。脚本不保证平台认定课程完成。

## 适用页面

```text
https://cx.wanfangdata.com.cn/e-training/quality/courselearn?courseId=...
https://cx.wanfangdata.com.cn/e-training/lecture/courselearn?courseId=...
```

面板匹配整个 `https://cx.wanfangdata.com.cn/e-training` 及其子路径：首页、列表页等没有课程视频时，显示“等待课程播放器”。进入课程后自动检测，无需修改课程 ID；精品课程和讲座课程使用相同的播放器容器。需要先通过网站正常登录。

从培训首页通过站内链接切换到课件时，已有脚本继续工作。面板在文档加载后挂载，并在页面重新渲染移除面板时重新挂载。安装或更新脚本后，仍需要先刷新已打开的页面一次，以加载新版本。其他培训系统、万方培训站点以外的路径及手机 App 不在当前适配范围内。

## 功能

| 功能 | 行为 |
| --- | --- |
| 后台播放 | 处理当前页面基于 `visibilityState` 的隐藏后自动暂停检测 |
| 倍速选择 | 在“设置”中选择 1、1.5、2、3、4、8×，默认 1×；实际支持范围取决于浏览器与播放器 |
| 自动下一节 | 在“设置”中自行开启或关闭，触发进度可设为 1–100% 的整数；默认开启、95%，达到后点击网站原有的“下一节”按钮 |
| 暂停后自动播放 | 默认开启，打开课程、新视频加载或后续视频暂停时尝试恢复；可在面板“设置”中关闭 |
| 状态面板 | 页面右下角显示课程标题、醒目的进度数字与进度条，以及播放状态和实际倍速；倍速和跳转选项集中在折叠的“设置”中 |
| 运行日志 | 展开查看启动、调速、切换、停止和异常记录；保留最近 60 条 |
| 拖动面板 | 拖动标题栏移动；标题栏聚焦后可用方向键移动，位置限制在当前视口内 |
| 切换开关 | 勾选或取消“自动跳转下一节”，可以反复切换，不影响自动播放和倍速监控 |

进入随堂测验、找不到下一节按钮，或切换后 20 秒内未加载出可识别的新视频时，自动切换会关闭，对应勾选框自动取消；返回有效视频课程后可在设置中重新勾选“自动跳转下一节”。脚本不会自动答题，也不会绕过课程访问权限。

## 安装：Tampermonkey（推荐）

1. 从 [Tampermonkey 官网](https://www.tampermonkey.net/)安装与你浏览器对应的扩展。优先使用 Chrome 或 Edge；其他浏览器未完成兼容性验证。
2. 根据扩展提示启用用户脚本执行权限。Chrome 138+ 可在扩展详情页启用“允许用户脚本”；部分 Chrome / Edge 版本需要开发者模式。具体步骤见 [Tampermonkey 官方说明](https://www.tampermonkey.net/faq.php?q=Q209)。
3. 点击本 README 顶部的“安装脚本”，在 Tampermonkey 安装页确认安装。
4. 登录万方，进入课程播放页并刷新一次。
5. 确认右下角出现“课程助手”。脚本会尝试自动播放；浏览器若限制首次自动播放，请手动点击播放一次。

如果安装链接只显示代码或下载文件，可用以下方式安装：

1. 在 Tampermonkey 菜单中选择“添加新脚本”。
2. 删除编辑器中的模板代码。
3. 将 [脚本文件](./wanfang-background.user.js)的**全部内容**粘贴进去，保留顶部 `==UserScript==` 元信息。
4. 保存，确认脚本已启用，再刷新课程页。

Raw 链接和手动新建脚本的安装方式也可参考 [Tampermonkey 官方安装说明](https://www.tampermonkey.net/faq.php?q=Q102)。

已安装过旧版时，请更新或替换旧脚本，避免同时启用多个副本。

## 临时使用：浏览器 Console

1. 登录并打开课程播放页。
2. 按 `F12` 或 `Ctrl + Shift + I` 打开开发者工具，切到 Console（控制台）。
3. 审阅 [脚本源码](./wanfang-background.user.js)，复制全部内容，粘贴执行。
4. 确认右下角出现面板，等待自动播放；如果浏览器拦截，请手动点击播放一次。

临时运行只对当前页面生效，刷新后需要重新运行。浏览器若限制控制台粘贴，可改用 Tampermonkey 安装方式。

## 面板怎么用

- **“● 运行中”** 表示监控程序正在工作，不代表视频一定在播放。“● 跳转关闭”表示仅关闭了自动跳转。播放进度区域单独显示“播放中”“已暂停”“已结束”或“等待课程播放器”。进度数字是视频播放位置，不是平台累计观看时长。
- **设置 → 播放倍速**直接调节当前视频，后续视频沿用当前选择。刷新后默认恢复 1×。
- **设置 → 暂停时自动播放** 默认开启，包括初次打开课件、新视频加载和后续暂停。关闭后脚本不再主动播放视频，也不会主动播放刚切换到的下一节；需要手动点击播放。设置在当前页面内生效，刷新后默认开启。
- **拖动标题栏** 可移动整个面板，鼠标和触摸均使用 Pointer Events。也可以聚焦标题栏，用方向键每次移动 10 像素。位置在当前页面内生效，刷新后恢复右下角。
- **日志**点击即可展开或收起，设置也默认折叠。记录仅保留在当前页面内存中，刷新后清空。
- **设置 → 自动跳转下一节** 默认开启。取消勾选只关闭下一节跳转，后台播放、倍速调节、暂停后自动播放和状态监控继续工作。重新勾选即可开启，无需刷新。要保留视频暂停状态，请同时关闭“暂停时自动播放”。
- **设置 → 跳转进度** 默认 95%，可输入 1–100 的整数；100% 表示播完后跳转。输入后移开焦点或按 Tab 生效，非法值会提示并恢复原设置。关闭自动跳转时也能修改进度，但不会触发跳转；重新开启后按当前设置执行。若当前播放位置已达到设定进度，下一次检查就可能跳转。
- **设置范围** 倍速、自动播放、跳转开关和跳转进度在当前页面内生效，后续章节沿用；刷新后恢复默认值（1×、自动播放开启、自动跳转开启、95%）。
- **重复执行** 会清理旧面板、定时器和挂载观察器，再启动当前版本，避免多个脚本同时跳转。

要彻底恢复原页面行为，油猴方式先禁用脚本再刷新；Console 方式直接刷新。不要同时安装和临时执行不同版本。

## 可选配置

倍速、自动跳转开关和跳转进度均可直接在面板“设置”中调整，无需修改源码。也可以在 Console 中执行：

```javascript
window.wanfangSpeed = 3; // 设为 3 倍速，轮询运行时会自动应用
wanfangAutoNextStop();  // 只关闭自动切换；可在设置中重新勾选开启
```

## 观看时长与完成状态

页面代码显示，视频播放期间约每分钟保存一次进度；页面提示的达标条件包括播放进度超过 90%、累计观看时长至少达到原时长的 90%。这是对当前页面代码的观察，后端最终判定仍以平台为准。

脚本使用浏览器原生播放倍速和网站“下一节”按钮。它不改写平台累计时长，不伪造学习记录，也不自行调用学习记录接口。网站自身的正常记录请求仍由网站发出。

如果需要满足累计时长要求，使用 1× 并检查平台进度；倍速到 95% 后跳转不能保证完成。即使将跳转位置改为 100%，倍速播放仍可能不满足累计时长要求。

## 常见问题

| 问题 | 处理方式 |
| --- | --- |
| 没有出现面板 | 确认位于 `/e-training` 站点，脚本版本是 1.4.0 或更新版本、已启用，扩展有用户脚本执行权限；更新后先刷新一次 |
| 站内跳转后只有刷新才出现 | 新版本匹配整个培训站点，能够从首页进入课件后继续检测；先刷新已打开的旧页面，让新版接管 |
| 一直显示等待播放器加载 | 先正常进入一节视频课程；测验、文档或播放器加载失败时不一定有可识别的 `video` 元素 |
| 切出后仍会暂停 | 确认只启用了一个脚本副本；网站可能更换检测逻辑，提交问题时说明具体切换方式 |
| 8× 不生效或提示不支持 | 选择 2× / 3× 等较低倍速，查看日志；可选倍速不等于所有浏览器都支持 |
| 达到设定进度后未跳转 | 在设置中确认“自动跳转下一节”已开启、跳转进度正确、视频正在播放或已结束，且存在下一节按钮；关闭自动播放并暂停时不会跳转，后台定时器可能被节流 |
| 关闭自动切换后想重新开启 | 在设置中重新勾选“自动跳转下一节”，不需要刷新 |
| 想播完后再跳转 | 将设置中的“跳转进度”改为 100%，并开启“自动跳转下一节” |
| 视频暂停后又自动播放 | 默认行为；展开“设置”，关闭“暂停时自动播放”即可保留暂停 |
| 打开课程或下一节没有自动播放 | 确认设置已开启；浏览器可能限制自动播放，请手动点击播放。失败时脚本每 5 秒重试，日志不连续刷屏 |
| 提示下一节加载超时 | 检查网络和章节内容，必要时刷新重新运行；脚本会停止，避免连续误跳 |
| 遇到测验后停止 | 手动完成测验，返回视频课程后在设置中重新勾选“自动跳转下一节” |
| 倍速后课程未完成 | 检查累计观看时长，这与视频播放位置是不同指标 |

脚本不能让关闭的标签页继续播放，也不能阻止电脑睡眠、系统休眠或浏览器冻结标签页。后台计时被节流时，状态刷新和自动切换可能延迟。

## 开发与反馈

仓库没有 npm 依赖或构建步骤。使用 Node.js 22 可运行检查：

```bash
node --check wanfang-background.user.js
node check.cjs
```

`check.cjs` 使用最小的播放器和 DOM 模型检查关键行为，不包含平台应用代码，不访问课程或学习记录接口。

反馈问题请在 [Issues](https://github.com/aurooooooo/wanfang-course-helper/issues) 提供浏览器和版本、脚本版本、问题发生步骤、相关运行日志。请移除账号密码、验证码、Cookie、Token 及个人信息。

## 隐私与许可

脚本不主动读取账号密码、Cookie 或 Token，不内置第三方统计或外部依赖。它只操作当前课程页面，显示本地运行日志。Tampermonkey 可按其更新设置从本仓库检查和获取脚本更新。
