# 万方课程助手

用于万方科研诚信培训系统课程播放页的浏览器用户脚本。提供后台继续播放、倍速调节、95% 自动下一节，以及带运行日志的悬浮控制面板。

**[安装脚本](https://raw.githubusercontent.com/aurooooooo/wanfang-course-helper/main/wanfang-background.user.js)** · [查看源码](./wanfang-background.user.js) · [反馈问题](https://github.com/aurooooooo/wanfang-course-helper/issues)

> 倍速播放不会同步增加平台累计观看时长。2 倍速播放到视频的 95%，本次实际只经过原视频时长的约 47.5%；课程可能仍未达标。脚本不保证平台认定课程完成。

## 适用页面

```text
https://cx.wanfangdata.com.cn/e-training/quality/courselearn?courseId=...
```

无需修改课程 ID。脚本只在上述课程播放路径运行，需要先通过网站正常登录。其他培训系统、万方其他学习路径及手机 App 不在当前适配范围内。

## 功能

| 功能 | 行为 |
| --- | --- |
| 后台播放 | 处理当前页面基于 `visibilityState` 的隐藏后自动暂停检测 |
| 倍速选择 | 默认 2×，面板可选择 1、1.5、2、3、4、8×；实际支持范围取决于浏览器与播放器 |
| 自动下一节 | 实际视频进度达到 95% 时，点击网站原有的“下一节”按钮 |
| 自动续播 | 等待新视频加载后尝试播放；被浏览器拦截时提示手动点击播放 |
| 状态面板 | 页面右下角显示监控状态、视频播放或暂停状态、实际倍速、进度与章节名称 |
| 运行日志 | 展开查看启动、调速、切换、停止和异常记录；保留最近 60 条 |
| 停止控制 | 手动暂停视频会被保留；可单独停止自动切换 |

进入随堂测验、找不到下一节按钮，或切换后 20 秒内未加载出可识别的新视频时，自动切换会停止。脚本不会自动答题，也不会绕过课程访问权限。

## 安装：Tampermonkey（推荐）

1. 从 [Tampermonkey 官网](https://www.tampermonkey.net/)安装与你浏览器对应的扩展。优先使用 Chrome 或 Edge；其他浏览器未完成兼容性验证。
2. 根据扩展提示启用用户脚本执行权限。Chrome 138+ 可在扩展详情页启用“允许用户脚本”；部分 Chrome / Edge 版本需要开发者模式。具体步骤见 [Tampermonkey 官方说明](https://www.tampermonkey.net/faq.php?q=Q209)。
3. 点击本 README 顶部的“安装脚本”，在 Tampermonkey 安装页确认安装。
4. 登录万方，进入课程播放页并刷新一次。
5. 确认右下角出现“课程助手”，然后手动点击视频播放。

如果安装链接只显示代码或下载文件，可用以下方式安装：

1. 在 Tampermonkey 菜单中选择“添加新脚本”。
2. 删除编辑器中的模板代码。
3. 将 [脚本文件](./wanfang-background.user.js)的**全部内容**粘贴进去，保留顶部 `==UserScript==` 元信息。
4. 保存，确认脚本已启用，再刷新课程页。

Raw 链接和手动新建脚本的安装方式也可参考 [Tampermonkey 官方安装说明](https://www.tampermonkey.net/faq.php?q=Q102)。

已安装过旧版时，请更新或替换旧脚本，避免同时启用多个副本。

## 临时使用：浏览器 Console

1. 登录并打开课程播放页。
2. 按 `F12` 或 `Ctrl + Shift + I` 打开开发者工具，切到 Console（控制台）。
3. 审阅 [脚本源码](./wanfang-background.user.js)，复制全部内容，粘贴执行。
4. 确认右下角出现面板，手动开始播放。

临时运行只对当前页面生效，刷新后需要重新运行。浏览器若限制控制台粘贴，可改用 Tampermonkey 安装方式。

## 面板怎么用

- **“● 运行中”**表示监控程序正在工作，不代表视频一定在播放。视频状态会单独显示为“正在播放”“视频已暂停”或“等待播放器加载”。
- **倍速下拉框**直接调节当前视频，后续视频沿用当前选择。刷新后默认恢复 2×。
- **运行日志**点击即可展开或收起。记录仅保留在当前页面内存中，刷新后清空。
- **“停止自动切换”**会停止进度轮询、后续自动切换和倍速自动同步；当前倍速及后台播放补丁仍保留，面板仍可手动调整倍速。
- **重新启动自动切换**：油猴安装方式刷新页面即可；Console 方式重新执行完整脚本即可。重复执行会替换旧面板和定时器。

要彻底恢复原页面行为，油猴方式先禁用脚本再刷新；Console 方式直接刷新。不要同时安装和临时执行不同版本。

## 可选配置

日常调速直接使用面板即可。也可以在 Console 中执行：

```javascript
window.wanfangSpeed = 3; // 设为 3 倍速，轮询运行时会自动应用
wanfangAutoNextStop();  // 停止自动切换
```

如需修改自动跳转位置，编辑脚本中的：

```javascript
const threshold = 0.95; // 95%；改为 1 表示到视频结束后再切换
```

修改后保存并刷新。自行修改脚本可能在后续更新时被覆盖，更新前请保留自己的设置。

## 观看时长与完成状态

页面代码显示，视频播放期间约每分钟保存一次进度；页面提示的达标条件包括播放进度超过 90%、累计观看时长至少达到原时长的 90%。这是对当前页面代码的观察，后端最终判定仍以平台为准。

脚本使用浏览器原生播放倍速和网站“下一节”按钮。它不改写平台累计时长，不伪造学习记录，也不自行调用学习记录接口。网站自身的正常记录请求仍由网站发出。

如果需要满足累计时长要求，使用 1× 并检查平台进度；倍速到 95% 后跳转不能保证完成。即使将跳转位置改为 100%，倍速播放仍可能不满足累计时长要求。

## 常见问题

| 问题 | 处理方式 |
| --- | --- |
| 没有出现面板 | 确认 URL 是适用路径、脚本已启用、扩展有用户脚本执行权限；刷新课程页 |
| 一直显示等待播放器加载 | 先正常进入一节视频课程；测验、文档或播放器加载失败时不一定有可识别的 `video` 元素 |
| 切出后仍会暂停 | 确认只启用了一个脚本副本；网站可能更换检测逻辑，提交问题时说明具体切换方式 |
| 8× 不生效或提示不支持 | 选择 2× / 3× 等较低倍速，查看日志；可选倍速不等于所有浏览器都支持 |
| 到 95% 后未跳转 | 手动暂停时不会跳转；确认自动切换仍在运行、存在下一节按钮；后台定时器可能被浏览器节流 |
| 下一节没有自动播放 | 浏览器可能限制自动播放，手动点击播放后继续观察 |
| 提示下一节加载超时 | 检查网络和章节内容，必要时刷新重新运行；脚本会停止，避免连续误跳 |
| 遇到测验后停止 | 手动完成测验，返回视频课程后刷新或重新运行脚本 |
| 倍速后课程未完成 | 检查累计观看时长，这与视频播放位置是不同指标 |

脚本不能让关闭的标签页继续播放，也不能阻止电脑睡眠、系统休眠或浏览器冻结标签页。后台计时被节流时，状态刷新和自动切换可能延迟。

## 开发与反馈

仓库没有 npm 依赖或构建步骤。使用 Node.js 22 可运行检查：

```bash
node --check wanfang-background.user.js
node check.cjs
```

`check.cjs` 使用最小的播放器和 DOM 模型检查关键行为，不包含平台应用代码，不访问课程或学习记录接口。

反馈问题请在 [Issues](https://github.com/aurooooooo/wanfang-course-helper/issues) 提供浏览器和版本、脚本版本、问题发生步骤、相关运行日志。请移除账号密码、验证码、Cookie、Token 及个人信息。

## 隐私与许可

脚本不主动读取账号密码、Cookie 或 Token，不内置第三方统计或外部依赖。它只操作当前课程页面，显示本地运行日志。Tampermonkey 可按其更新设置从本仓库检查和获取脚本更新。
